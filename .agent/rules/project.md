# Hackathon project rules (CampusSolve, solo, 6 hours)

## Always
- Read SPEC.md and TASKS.md before doing anything. They are the source of truth.
- Work ONLY on the task I give you. Do not add features, refactor, rename files or change the stack unless I ask.
- Keep the stack simple and free: Flask or Node, SQLite, Tailwind via CDN. No paid services.
- Write complete, runnable code. No placeholders, no TODOs, no "rest remains the same".
- The app must run with seeded demo data and with no internet or API key (use rule-based fallbacks for AI features).
- After every task: run the app, check the "done when" condition, and report: files changed, how to test, known issues. Keep the report under 10 lines.
- If something is unclear, state a one-line assumption and continue. Do not ask long questions.
- Stop when the "done when" condition is met.

## Never
- Do not install new heavy dependencies without telling me first.
- Do not delete files or the database without asking.
- Do not touch files outside the ones I list for the task.

## Quality floor
- Mobile-responsive, clean UI, proper empty and error states, no broken pages.
- Realistic Indian campus seed data so the demo looks alive.
